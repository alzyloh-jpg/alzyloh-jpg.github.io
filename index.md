## Overview

This project brings together the main notes, daily reflections, and reference material behind the Conveyor Belt work. The goal is to keep the project readable, easy to extend, and simple to maintain as new pages are added.

### Structure

- Home — project overview and landing page
- Day 1 — first research or project progression log
- Day 2 — second phase and updates
- Day 3 — continuing research and findings
- Sources — references, materials, and supporting links

---

## How to add new pages

1. Create a new `.html` file in the project root or a dedicated folder.
2. Add a link to that page below.
3. Keep the section titles short and descriptive.
4. Update the page list regularly so the home page remains the entry point.

### Example page list

- [New Research Note](new-research-note.html)
- [Interview Notes](interview-notes.html)
- [Photo Log](photo-log.html)

---

## Adding photos

Upload images into a folder such as `images/` and reference them in a page like this:

```html
<img src="images/conveyor-belt.jpg" alt="Conveyor belt working prototype">
```

Use clear file names, keep the images compressed, and add `alt` text for accessibility.
