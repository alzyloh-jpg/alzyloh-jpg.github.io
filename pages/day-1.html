Day 1

Understanding the working environment, Nero arm operation and safety, and Action Chunking with Transformers.

What is an environment?

An environment is a complete workspace of software, tools, and rules that allows code to run properly. It keeps everything organized and predictable so code runs reliably without breaking on different computers.

  • Operating system (OS): the foundation code runs on, such as Windows, macOS, or Linux.
  • Language and engine: the programming language and its interpreter or compiler, such as Python or C.
  • External libraries: pre-written packages that give a program extra features.
  • Settings and configuration: rules, paths, and credentials that tell code how to behave on a particular machine.

Nero robotic arm safety protocols [1]

  • The arm is not for anyone under 18; anyone under 18 must have adult supervision.
  • The arm has no obstacle avoidance or sensors. Use it in an open area and keep it in sight.
  • Stay within the stated operating conditions: −20 to 50 °C, 25–85% non-condensing humidity, and IP22 ingress protection.
  • The maximum payload is 3 kg.
  • If software reports an error, the arm moves unusually, or anyone enters its operating zone, press Emergency Stop.

Safety: Follow the manufacturer's manual and have a trained supervisor present. Keep people and objects clear of the arm's workspace; do not rely on the arm to detect them.

How the Nero arm works [1]

  1. Select a control mode: Point, Line, or Circle movement; direct joint angles; or a saved trajectory.
  2. For Point, Line, and Circle movements, specify a target position (x, y, z, and orientation). The controller calculates the joint angles needed to reach it.
  3. If the target or any point along its path is unreachable, the arm does not move and displays an error.
  4. Each joint motor moves to its commanded angle within its range and speed limits.

Features built on top of basic control

  • Drag teaching: gravity compensation counteracts the arm's weight so a person can move it by hand while its path is recorded. The path can then be replayed.
  • Leader–follower: one arm is moved by hand and a second arm copies its motion in real time.
  • Zero point: each joint has a reference angle used to determine its position. It must be set in the upright pose for gravity compensation to work correctly.
  • Protection: joint, speed, and acceleration limits and collision sensitivity (levels 0–8) can be configured. The arm stops if it encounters unexpected resistance.

Limitations and visual perception

The arm has no built-in cameras or obstacle sensors, so by itself it only knows its joint positions. It is not aware of objects or people. Tasks involving objects, such as picking up a block, therefore need external perception, which can use fixed positions, additional sensors, or cameras.

In this setup, cameras provide visual input. The arm can learn to pick up a cube using ACT (Action Chunking with Transformers), an imitation-learning policy that maps camera observations to arm actions.

What is ACT? [2]

Action Chunking with Transformers (ACT) is a low-cost, reproducible learning method that predicts sequences of future actions rather than one action at a time.

How it works

  • Data collection: train from human demonstrations paired with robot joint data.
  • Action chunking: predict a group, or “chunk,” of future actions at once to reduce small mistakes that accumulate over time.
  • Temporal ensembling: querying only every k steps can make movement jerky when new observations arrive. Querying at every timestep creates overlapping predictions; a weighted average blends them into smoother motion. The notes give exponential weights as wᵢ = exp(−m · i).

Challenges and approaches noted

  • Jerky motion: blend overlapping predictions with temporal ensembling.
  • Noisy human demonstrations: humans vary their movements when precision is not needed; training should prioritize accuracy at critical, high-precision moments.
  • Unpredictable tasks: tasks such as unwrapping candy may need more data, pretraining, and better visual perception.

Difficulties faced with the Nero arm
